# Rock Paper Scissors

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript. The game is played against the computer, which makes random choices using the `Math.random()` function.

## Features
- Play against the computer
- Randomized computer moves
- Instant result display
- Simple and interactive UI

## Technologies Used
- **HTML**: Structure of the game
- **CSS**: Styling for an engaging interface
- **JavaScript**: Game logic and random selection

## How to Play
1. Open `index.html` in a web browser.
2. Choose **Rock**, **Paper**, or **Scissors** by clicking the respective button.
3. The computer will randomly select its move.
4. The winner will be determined based on standard Rock Paper Scissors rules:
   - Rock beats Scissors
   - Scissors beats Paper
   - Paper beats Rock
   - The same choices result in a draw
5. The result is displayed instantly.
